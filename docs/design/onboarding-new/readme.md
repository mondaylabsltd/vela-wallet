
这套设计用了三款字体，全部来自你 Token Guide 的 font stack：

 **Plus Jakarta Sans** (400/500/600/700/800) — 拉丁文界面主字体：字标 VELA WALLET、按钮、标题、正文。

 **Noto Sans SC** (400/500/700/900) — 中文界面字体，与上面同一角色、同一字重层级，中英混排共用一套 typography role。

 **JetBrains Mono** (400/500) — 数值与标识：钱包地址、密钥计数 1 / 7、进度百分比、底部导航标签。

离线文件里这三款的所需字重都已内联，不联网也能正确显示。之前误加过 Source Serif 4 / Noto Serif SC 做衬线标题，已全部移除。
