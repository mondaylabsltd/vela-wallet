# 通行密鑰點運作

Vela 成套安全模型都落喺一件事上面：控制你個錢包嗰把鎖匙係一把**通行密鑰**，
由你部機生成、由你個作業系統保管——任何應用都讀唔到，Vela 都一樣——而且淨係喺你
刷完臉或者撳完指紋之後先會俾人用。

## 通行密鑰到底係乜

通行密鑰係由你部機生成嘅一對公私鑰。**私鑰**由作業系統嘅通行密鑰服務保管——
喺 Apple 通常係 iCloud 鑰匙串，喺 Android 係 Google 密碼管理工具——以端對端加密
方式存放，所以任何應用都讀唔到、亦複製唔走。應用攞唔到把鎖匙；佢哋做得到嘅，
係喺你認證之後*請求你部機簽個名*。

呢套技術，同保護 Apple Pay 同你生物解鎖嗰套係同一樣嘢。

<Callout type="info" title="重點">
應用——包括 Vela——可以請求一個簽名，但佢永遠睇唔到你個私鑰。你張臉或者隻手指
授權部機去簽；把鎖匙本身留喺作業系統手上，端對端加密。
</Callout>

## 點解冇嘢可以俾人釣走

釣魚之所以得手，係因為佢氹到你交出一個秘密。助記詞嘅情況下，嗰個秘密係十二個
你可以打入假網頁嘅英文字。而通行密鑰**根本冇一個可以輸入嘅秘密**。呃人嘅網站冇得
叫你「輸入你嘅通行密鑰」，因為通行密鑰唔係攞嚟輸入嘅——佢係一次由你嘅生物認證
把關嘅硬件操作。

自我保管嘅錢最常見嗰種損失方式，就咁樣冇咗。

## 簽一筆交易係點樣

1. 你喺 Vela 裡面確認一筆交易。
2. 部機彈 Face ID / Touch ID 提示。
3. 部機用你把通行密鑰簽低呢筆交易。
4. Vela 將簽好嘅交易廣播上網絡。

同解鎖部電話係同一個動作——因為佢本來就係你部機喺第度一直用緊嗰套通行密鑰機制。

<Callout type="warning" title="部機本身嘅安全一樣緊要">
通行密鑰對遠端攻擊同釣魚嘅防護非常好。但佢擋唔住一個已經攞到你未鎖定嘅機、
又過得到你生物認證嘅人。請設定好裝置密碼，亦唔好將解鎖咗嘅電話交俾你唔信得過嘅人。
</Callout>
