# 開你個錢包

開一個錢包大約要一分鐘，加上一次生物認證。打開網頁錢包
[wallet.getvela.app](https://wallet.getvela.app/)，揀**開錢包**。

## 步驟

1. **幫個錢包改個名。** 改個名，方便你之後認返呢個帳戶，亦方便喺另一部機登入嗰陣
   分得出邊個係邊個。佢同你個公鑰擺埋一齊，所以當成公開資料——唔好寫任何私密嘢
   落去。
2. **確認幾樣基本嘢。** 一份好短嘅清單，確認你明白 Vela 係自我保管、而且仲係測試版
   軟件，入面有[私隱政策](/privacy)同[服務條款](/terms)嘅連結。
3. **整你把通行密鑰。** 出提示嗰陣，用 **Face ID、Touch ID 或者指紋**認證。
   呢一步會生成一把 WebAuthn（P-256）通行密鑰，由你部機保管，Vela 永遠睇唔到。
   呢度冇「抄助記詞」嗰一步，因為根本冇助記詞。
4. **完成。** Vela 會顯示你個錢包地址，你就入到去喇。你可以核對個地址，然後登入
   入自己個錢包。

## 你個錢包到底係乜

呢一段大部分錢包唔會解釋——但係佢決定咗 Vela 係點運作。

你個 Vela 錢包係一個 **Safe 智能帳戶**（一份智能合約），而唔係一個普通嘅
「外部擁有帳戶」。你把通行密鑰係呢個帳戶嘅擁有者；ERC-4337 嗰套令你可以淨係用
張臉或者隻手指去操作佢。

<Callout type="info" title="喺每條網絡上面都係同一個地址">
Vela 由你通行密鑰嘅公鑰推導出地址，所以佢喺以太坊、Base、Arbitrum、Gnosis
同其他所有支援嘅網絡上面完全一樣。一個地址，去邊都畀得。
</Callout>

仲有一個幾有用嘅結果：呢個地址係**反事實（counterfactual）**嘅。佢喺鏈上部署任何
嘢之前就計得出，所以**喺錢包合約存在之前，你已經可以用呢個地址收錢**。合約會喺你
第一次喺某條網絡發交易嗰陣，用佢自己嘅餘額找數、將自己部署上去。

## 頭先你啲鎖匙發生咗啲乜

- 你部機生成咗一對**通行密鑰嘅鑰匙對**。
- **私鑰**由你作業系統嘅通行密鑰服務保管（iCloud 鑰匙串或者 Google 密碼管理工具），
  以端對端加密方式儲存，並喺你啲裝置之間同步——任何應用都睇唔到，Vela 都一樣。
- **公鑰同你改嗰個名**會發布去 Vela 嘅通行密鑰索引，佢同時將公鑰寫入 Gnosis Chain
  上面一份任何人都讀得到嘅紀錄，等你個帳戶喺新機上面仲搵得返。
  睇[復原同登入](/zh-HK/docs/recovery)。
