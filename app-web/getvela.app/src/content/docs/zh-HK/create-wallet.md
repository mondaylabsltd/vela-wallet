# 建立錢包

建立錢包大約需要一兩分鐘。打開網頁版錢包 [wallet.getvela.app](https://wallet.getvela.app/)——或擴充功能、
桌面版、手機 App——然後選擇**建立錢包**。

## 步驟

1. **為錢包命名。**名稱方便你辨認錢包，它會和你的鑰匙一起寫入公開註冊表——請把它當作公開資料，
   不要寫入任何私人內容。
2. **確認將會發生的事。**你需要剔選確認：你的公鑰和錢包名稱會寫到鏈上；你的私鑰會留在你的裝置或安全密鑰中；
   以及你同意[服務條款](/terms)和[私隱政策](/privacy)。
3. **建立第一把鑰匙。**選擇方式：**本裝置**（Face ID、Touch ID、指紋、Windows Hello）、**手機或平板電腦**
   （掃描 QR 碼，在那部裝置上建立；視乎 App 是否提供此選項），或 **USB 安全密鑰**。你的裝置建立通行密鑰後，會用它簽署一次，
   讓 App 在繼續之前確認這把鑰匙真的可用。
4. **如有需要，加入更多鑰匙。**總共最多七把，種類不限。之後其中任何一把都能單獨簽署。如果你唯一的鑰匙沒有
   同步到任何地方——例如安全密鑰或 Windows Hello——App 會要求你再加一把，因為只有一把未同步的鑰匙，
   遺失一部裝置就等於遺失錢包。
5. **建立。**App 根據整組鑰匙計算出錢包地址，並把這組鑰匙發佈到 Gnosis Chain 上的公開註冊表。這條紀錄
   上鏈後，錢包就會打開。

<Callout type="warning" title="現在就選好鑰匙">
地址是由你最終確定的那組鑰匙計算出來的，所以之後不能加入、移除或更換鑰匙。[簽署鑰匙與安全密鑰](/zh-HK/docs/signers)
說明了原因，以及怎樣選擇。
</Callout>

## 你的錢包是甚麼

你的錢包是一個 **Safe 智能帳戶**——一份合約，而不是只有一把私鑰的普通帳戶。你的鑰匙是它的擁有者，
其中任何一把都能授權交易。涉及的每一份合約都列在[帳戶合約](/zh-HK/docs/account-contract)中。

地址**在每條網絡上都相同**，而且是**反事實（counterfactual）**的：在部署任何東西之前就已經計算出來，
所以你可以馬上在任何網絡上收款。你第一次從某條網絡轉出時，合約會自行部署，這第一筆交易的手續費已包含部署費用。
建立錢包本身不用花錢。

## 哪些內容會公開

<span id="what-is-public"></span>

建立錢包時，會在 Gnosis Chain 上的一份公開註冊表合約寫入一條永久紀錄，任何人都能讀取，而且無法修改或刪除：

- 每把鑰匙的**公鑰**（絕不是私鑰）及其**憑證 ID**；
- 每把鑰匙的**驗證器型號**（由哪個密碼管理工具或安全密鑰產生），以及表示你是否已通過驗證、鑰匙是否同步的標記；
- **錢包名稱**和**每把鑰匙的名稱**；
- **錢包地址**及其建立時間；
- **已簽署的登記資料**本身。

這條紀錄由 Vela 的公鑰索引提交並支付 gas，所以它會最先看到紀錄內容。紀錄中沒有任何能動用你資金的東西；
正是它讓你任何一把鑰匙都能在新裝置上重新找到錢包（見[復原](/zh-HK/docs/recovery)）。完整清單見
[私隱政策](/privacy)，[註冊表頁面](/registry)則顯示每一條紀錄。
