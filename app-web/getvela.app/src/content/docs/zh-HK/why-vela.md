# 我們為甚麼做 Vela

我們本來沒有打算再做一個錢包。一切始於一個我們始終答不好的問題：

> 那十二個單詞，究竟應該放在哪裏？

## 誠實的答案是一張截圖

存在備忘錄裏，手機一被偷就會出事。寫在紙上，你就要開始擔心火災、水浸、搬屋、室友、垃圾袋，
還有將來的你是否仍記得「那個安全的地方」在哪裏。

對很多人來說，誠實的答案是：相簿裏的一張截圖。人人都知道這樣不對，卻還是這樣做——因為那個
「正確」的做法，實在難以在日常生活中堅持下去。

助記詞是一個秘密，它要在幾十年的日常生活中安然無恙：從沒被複製、從沒被拍照、從沒被輸入錯誤的
欄位，也從沒在電話裏讀給某個「熱心人」聽。對一個小心謹慎的人來說，這不算難題。對一個人來說，
這就是難題。

## 後來，通行密鑰改變了錢包給人的感覺

我們每天都在用 [Base Account](https://account.base.app)，用 Face ID 簽署是那麼理所當然，這是
助記詞從未給過的感覺——不像在處理危險品，更像在使用互聯網上的其他服務。

但用得越久，就越常碰到一些無法忽視的限制：

- 一把**在瀏覽器中產生的復原密鑰**，你只能選擇相信它；
- **不能加入自訂網絡**；
- **無法自行架設**；
- 以及那個不聲不響、卻是最大的問題：**服務一旦消失，錢包也會跟着消失。**

於是我們做了一個自己願意依賴的版本。

## Vela 究竟是甚麼

Vela 是**一個你可以完全擁有的通行密鑰錢包。**

你的通行密鑰留在你的裝置本來就在保護它的地方——iCloud 鑰匙圈、Google 密碼管理工具，或你手上的
硬件安全密鑰。你簽署交易時，Vela 請你的裝置簽署；裝置完成簽署後，只傳回簽名本身。Vela 從來
看不到鑰匙。

大多數錢包仍然有一個危險的時刻，即使很短暫：螢幕上的單詞、記憶體中的助記詞、放在瀏覽器分頁裏的
復原密鑰。Vela 的設計讓這個時刻根本不存在。

<Callout type="info" title="不是承諾，而是架構">
我們無法接觸你的鑰匙。不是「我們承諾不會」——Vela 中根本沒有任何程式碼路徑可以做到，WebAuthn 也不容許。
這個錢包是一個 <a href="/zh-HK/docs/account-contract">Safe 智能帳戶</a>，由你的裝置產生、我們只會收到的簽名來操作。
你用來簽署的 App 確實能決定的，是要你的鑰匙簽署<em>甚麼</em>——這也是
<a href="/zh-HK/docs/whitepaper">威脅模型</a>花大量篇幅討論它的原因。
</Callout>

我們把 Vela **開源**，是為了讓你可以親自查證這一點；把它做成**可自行架設**，是為了讓現有的錢包在
沒有我們公司伺服器的情況下也能繼續運作——只有一個限制，就是你的通行密鑰所屬的域名，
[自行架設指南](/zh-HK/docs/self-hosting)說明了這個限制，以及繞過它的方法。我們建基於未經修改的
[Safe 合約](https://github.com/safe-fndn/safe-smart-account/tree/release/v1.4.1)，
因為涉及別人的錢時，走那條平淡卻久經考驗的路才是對的——正是這些合約，已經在鏈上守護着數以十億計的資產。

## 我們選擇的取捨

取捨依然存在，把它藏起來是不誠實的。

使用 Vela，你的 Apple 或 Google 帳戶就變得重要，因為同步的通行密鑰就存放在那裏。失去那個帳戶，
或刪除了通行密鑰，就沒有助記詞、沒有客服重設，也沒有後門。

但每一個自我託管錢包，都要你選擇寧願承受哪一種風險。助記詞可以被複製、被截圖、被釣魚騙走，或在
凌晨一點被輸入錯誤的網站。通行密鑰不一樣：沒有可以洩露的單詞，沒有可以貼上的秘密，也沒有任何
假網站能騙你交出它。你的瀏覽器只會把它提供給真正域名上的頁面。

而且這個選擇不是非此即彼。建立錢包時最多可以設定**七把簽署鑰匙**，其中任何一把都能單獨簽署——
不同裝置上的通行密鑰、一部你掃描 QR 碼連接的身邊手機，或一把 USB/NFC 安全密鑰。如果你寧願錢包
完全不依賴任何平台帳戶，可以只用硬件安全密鑰——要兩把，因為錢包不能只靠一把不同步到任何地方的
鑰匙。唯一的條件是時機：你的地址是由整組鑰匙推導出來的，所以鑰匙要在建立錢包時選定。

<Callout type="warning" title="這樣做換不到的東西">
多加的簽署鑰匙是一條回到錢包的路，不是第二道鎖。因為任何一把鑰匙都能單獨簽署，加一把硬件密鑰保護的是
你不會<em>失去</em>存取權——它擋不住已經取得你其中一把鑰匙的人。這就是 1-of-n 的真實面貌。
</Callout>

## 這就是 Vela 存在的原因

一個沒有助記詞要收藏、沒有復原密鑰要信任，也不用祈求哪家公司永遠存在的錢包。

如果你想查證這些說法，而不是照單全收：[白皮書](/zh-HK/docs/whitepaper)有完整的架構，
[審計與已知問題](/zh-HK/docs/security-audits)列出了我們依賴的每一份合約，以及哪些經過審計、哪些沒有，
而全部程式碼都[在 GitHub 上](https://github.com/mondaylabsltd/vela-wallet)。
