# Vela 文件

Vela 是一款**給以太坊和其他 EVM 網路用的自我保管錢包**，沒有助記詞。你的錢包是一個未經修改的
[Safe](/zh-TW/docs/account-contract) 智慧帳戶，你用**密碼金鑰**簽署——可以在你的手機或電腦上、
另一支手機上，或一把硬體安全金鑰上。

- **你的金鑰，最多七把。** 在建立錢包時選定；其中任何一把都能簽署。Vela 從來不持有它們，在你的錢包上也沒有任何角色。
- **24 條網路，同一個位址。** 另外還能新增任何符合條件的 EVM 網路。
- **先看懂，再簽署。** 交易會被解碼成白話；解不開的會明確標示出來。
- **沒有我們也能運作。** 應用程式和服務都是開源的，也都能換掉——限制在哪裡，[自架指南](/zh-TW/docs/self-hosting)都寫清楚了。
- **Alpha 階段。** 它能正常使用、放著真實的資金，但還很年輕：請先從小額開始。
  [這裡說的 alpha 是什麼意思](/blog/vela-is-in-alpha)。
