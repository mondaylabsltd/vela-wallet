# 簡介

Vela 是一個給 EVM 網路用的**自我保管智慧錢包**。金鑰在你手上，但沒有助記詞要抄下來
——你用密碼金鑰簽署，靠的是你的臉或是指紋。

這份文件會談怎麼開始、怎麼建立錢包、怎麼轉移代幣，以及它背後的安全模型是怎麼一回事。

## 一句話版本

- **自我保管。** 你的資金由一把只有你能用的金鑰控制。Vela（這家公司）無法轉移、
  凍結或是幫你取回你的錢。
- **沒有助記詞。** 你的簽署金鑰是一把存在裝置安全硬體裡的密碼金鑰。不存在那種
  會弄丟、會被釣走的十二個單字。
- **一個 Safe 智慧帳戶。** 每個錢包都是一份 [Safe](https://github.com/safe-fndn/safe-smart-account)
  智慧合約，透過 ERC-4337 帳戶抽象來操作——正是它讓你可以用密碼金鑰簽署，
  並且在核准之前讀懂每一筆交易。
- **12 條網路，同一個位址。** 以太坊、BNB Chain、Polygon、Arbitrum、Optimism、
  Base、Avalanche、Gnosis、Unichain、Tempo、Monad 與 World Chain——再加上你自己
  新增的網路——全都是同一個位址。
- **看得懂的簽署。** 只要有對應的描述符，交易就會被解碼成人看得懂的意圖
  （ERC-7730）；沒有的話，Vela 會退回盡力而為的解碼並給出警告。解不開的呼叫
  會被標示出來，而不是藏起來。
- **開放原始碼。** 錢包和它的所有服務都[公開在 GitHub 上](https://github.com/mondaylabsltd/vela-wallet)，
  任何人都可以查核它們到底做了什麼。
- **仍是 alpha 軟體。** Vela 能用，也真的放著實際的錢，但它還沒有經過多年的正式
  環境磨練。請從小額開始。[alpha 說明](/blog/vela-is-in-alpha)講清楚了這代表什麼。

## 它為誰而做

Vela 是為那些想要真正自我保管、又不想被助記詞管理坑到的人做的——也為那些已經被
坑過一次的人。只要你解得開自己的手機，你就用得了 Vela。
