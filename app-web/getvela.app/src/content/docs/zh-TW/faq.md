# 常見問題

## Vela 是自我保管的嗎？

是。你的錢包是一個智慧帳戶，由一把只有你能用的金鑰控制；這把金鑰由你裝置的作業
系統保管，Vela 從來看不到。Vela 無法轉移、凍結或是幫你取回資金。

## 我的錢包是普通帳戶還是合約？

它是一個 **Safe 智慧帳戶**（一份智慧合約），透過 ERC-4337 帳戶抽象來操作。正是
這一點讓你可以用密碼金鑰簽署、在核准前讀懂每一筆交易，並且在每條網路上用同一個
位址。架構見[白皮書](/zh-TW/docs/whitepaper)。

## 真的沒有助記詞嗎？

真的沒有。你的簽署金鑰是一把由裝置作業系統保管的密碼金鑰，Vela 永遠看不到它。
沒有那十二個要抄下來、會弄丟、會被釣走的單字。為什麼這樣是安全的，見
[密碼金鑰如何運作](/zh-TW/docs/passkeys)。

## 手機掉了怎麼辦？

如果你的密碼金鑰透過 iCloud 鑰匙圈或 Google 密碼管理工具同步，那就在新裝置上用
同一個帳號登入，錢包就回來了。完整模型和它的邊界，見[復原與登入](/zh-TW/docs/recovery)。

## 支援哪些網路和代幣？

Vela 內建 **12 條 EVM 網路**——以太坊、BNB Chain、Polygon、Arbitrum、Optimism、
Base、Avalanche、Gnosis、Unichain、Tempo、Monad 與 World Chain——再加上你自己新增
的網路，可以持有原生代幣和 ERC-20。你的位址在所有網路上都一樣。見
[網路與費用](/zh-TW/docs/networks-and-fees)。

## 用起來要花多少錢？

錢包本身免費，Vela **沒有代幣**。你從自己的錢包餘額支付網路 **gas**，再加一筆
中繼費。價格由中繼報出，並且在**你簽署之前**以「網路費 / 中繼費 / 合計」的形式
顯示——每一筆交易的確切成本都在確認頁上，而且報出的金額是你所簽內容的一部分，
簽完就不會再變。非常便宜的交易可能會碰到一個很小的最低收費。在沒有原生幣的 Tempo
上，gas 用美元穩定幣結算。另外每條網路都需要一筆很小、**不可退還的押金來啟用它的
gas 中繼帳戶**（Vela 可能會替新使用者代付）；由於那個帳戶會慢慢用掉，之後你可能
還要再補一次——它並不是嚴格意義上的一次性支出。細節見
[網路與費用](/zh-TW/docs/networks-and-fees)。

## Vela（這家公司）看得到什麼、做得到什麼？

Vela 保存你密碼金鑰的**公鑰**和你取的**名字**，用於跨裝置登入。它看不到你的私鑰，
你的餘額是從公開鏈上讀取的，也沒有任何電子郵件註冊。以[隱私權政策](/privacy)為準。

## Vela 是開放原始碼的嗎？

是——錢包和它的四項後端服務（鏈上資料、密碼金鑰索引、中繼、匯率）都以 MIT 授權
[公開在 GitHub 上](https://github.com/mondaylabsltd/vela-wallet)，你也可以自行部署。
