# 建立你的錢包

建立一個錢包大約要一分鐘，加上一次生物辨識確認。打開網頁錢包
[wallet.getvela.app](https://wallet.getvela.app/)，選擇**建立錢包**。

## 步驟

1. **替錢包取個名字。** 取個名字，方便你之後認出這個帳戶，也方便在另一台裝置上
   登入時辨認。它和你的公鑰存在一起，所以請當成公開資訊——別把任何私密內容寫進去。
2. **確認幾件基本的事。** 一份很短的清單，確認你明白 Vela 是自我保管的、而且仍是
   alpha 軟體，裡面有[隱私權政策](/privacy)和[服務條款](/terms)的連結。
3. **建立你的密碼金鑰。** 出現提示時，用 **Face ID、Touch ID 或是指紋**驗證身分。
   這會產生一把 WebAuthn（P-256）密碼金鑰，由你的裝置保管，Vela 永遠看不到。
   這裡沒有「抄助記詞」那一步，因為根本就沒有助記詞。
4. **完成。** Vela 會顯示你的錢包位址，你就進去了。你可以核對位址，接著登入進到
   自己的錢包。

## 你的錢包到底是什麼

這一部分大多數錢包不會解釋——但它決定了 Vela 是怎麼運作的。

你的 Vela 錢包是一個 **Safe 智慧帳戶**（一份智慧合約），而不是一個普通的
「外部擁有帳戶」。你的密碼金鑰是這個帳戶的擁有者；ERC-4337 那一套讓你可以只靠
臉或是指紋來操作它。

<Callout type="info" title="在每條網路上都是同一個位址">
Vela 由你密碼金鑰的公鑰推導出位址，所以它在以太坊、Base、Arbitrum、Gnosis
以及其他所有支援的網路上完全一致。一個位址，到處都能給。
</Callout>

還有一個很有用的結果：這個位址是**反事實（counterfactual）**的。它在鏈上部署任何
東西之前就算得出來，所以**在錢包合約存在之前，你就可以用這個位址收款**。合約會在
你第一次在某條網路上送出交易時，用它自己的餘額付錢、把自己部署上去。

## 剛才你的金鑰發生了什麼

- 你的裝置產生了一對**密碼金鑰的金鑰對**。
- **私鑰**由你作業系統的密碼金鑰服務保管（iCloud 鑰匙圈或 Google 密碼管理工具），
  以端對端加密儲存並在你的裝置之間同步——任何應用程式都看不到它，Vela 也一樣。
- **公鑰和你取的名字**會發布到 Vela 的密碼金鑰索引，它同時把公鑰寫進 Gnosis Chain
  上一份任何人都讀得到的紀錄，好讓你的帳戶在新裝置上還能被找回來。
  見[復原與登入](/zh-TW/docs/recovery)。
