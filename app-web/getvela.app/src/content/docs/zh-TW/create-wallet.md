# 建立你的錢包

建立錢包大約需要一兩分鐘。打開網頁錢包 [wallet.getvela.app](https://wallet.getvela.app/)——或擴充功能、
桌面版、手機應用程式——選擇**建立錢包**。

## 步驟

1. **替錢包取個名字。** 名字是讓你認得它用的，它會和你的金鑰一起寫進公開註冊表——請把它當成公開資訊，
   不要放任何私人內容。
2. **確認會發生什麼事。** 你要勾選：你的公鑰和錢包名稱會寫上鏈；你的私鑰留在你的裝置或安全金鑰裡；
   以及你同意[服務條款](/terms)和[隱私權政策](/privacy)。
3. **建立第一把金鑰。** 選擇方式：**這台裝置**（Face ID、Touch ID、指紋、Windows Hello）、**手機或平板**
   （掃描 QR 碼，在那台裝置上建立；要看應用程式有沒有提供），或 **USB 安全金鑰**。你的裝置建立密碼金鑰後，會用它簽署一次，
   讓應用程式在繼續之前先確認這把金鑰真的能用。
4. **想要的話，再加幾把金鑰。** 總共最多七把，種類不限。之後其中任何一把都能單獨簽署。如果你唯一的那把金鑰
   沒有同步到任何地方——例如安全金鑰或 Windows Hello——應用程式會要你再加一把，因為只有一把沒同步的金鑰，
   掉一台裝置就等於掉了整個錢包。
5. **建立。** 應用程式用完整的一組金鑰算出錢包位址，並把這組金鑰發布到 Gnosis Chain 上的公開註冊表。
   這筆紀錄上鏈之後，錢包就會打開。

<Callout type="warning" title="現在就把金鑰選好">
位址是用你最後定案的那組金鑰算出來的，所以之後不能新增、移除或更換金鑰。[簽署金鑰與安全金鑰](/zh-TW/docs/signers)
說明了原因，也說明了該怎麼選。
</Callout>

## 你的錢包是什麼

你的錢包是一個 **Safe 智慧帳戶**——一份合約，而不是只有一把私鑰的普通帳戶。你的金鑰是它的擁有者，
其中任何一把都能授權交易。涉及的每一份合約都列在[帳戶合約](/zh-TW/docs/account-contract)裡。

位址**在每一條網路上都一樣**，而且是**預先算出的（counterfactual）**：在部署任何東西之前就已經算好，
所以你馬上就能在任何網路上收款。你第一次從某條網路送出交易時，合約會自行部署，部署費用包含在這第一筆交易的
手續費裡。建立錢包本身不用花錢。

## 哪些內容是公開的

<span id="what-is-public"></span>

建立錢包時，會在 Gnosis Chain 上的公開註冊表合約寫入一筆永久紀錄，任何人都能讀取，無法修改或刪除：

- 每把金鑰的**公鑰**（絕對不是私鑰）和**憑證 ID**；
- 每把金鑰的**驗證器型號**（由哪個密碼管理工具或安全金鑰產生），以及標示是否驗證過你本人、金鑰是否同步的旗標；
- **錢包名稱**和**每把金鑰的名稱**；
- **錢包位址**和建立時間；
- **簽署過的註冊資料**本身。

這筆紀錄由 Vela 的公鑰索引送出並支付 gas，所以它會最先看到紀錄內容。紀錄裡沒有任何能動用你資金的東西；
正是它讓你任何一把金鑰都能在新裝置上重新找到錢包（見[復原](/zh-TW/docs/recovery)）。完整清單請看
[隱私權政策](/privacy)，[註冊表頁面](/registry)可以看到每一筆紀錄。
