# Vela ドキュメント

Vela は、シードフレーズのない、**Ethereum とその他の EVM ネットワーク向けの、オープンソースでセルフホスト可能なウォレット**です。ウォレットは改変していない [Safe](/ja/docs/account-contract) のスマートアカウントで、署名には**パスキー**を使います。パスキーはスマートフォンやパソコンのほか、別のスマートフォンや、ハードウェアセキュリティキーにも置けます。

- **私たちがいなくても動く。**アプリと、それを支えるすべてのサービス（リレー、公開鍵インデックス、チェーンデータ、為替レート）は MIT ライセンスです。[セルフホスティングガイド](/ja/docs/self-hosting)に沿って、自分でビルドして動かせます。限界もそこに書いています。
- **鍵は最大 7 本。**ウォレットを作成するときに選び、そのうちどれか 1 本で署名できます。Vela が鍵を持つことはなく、ウォレットに対する権限もありません。
- **24 のネットワークで、ひとつのアドレス。**要件を満たす EVM ネットワークなら、自分で追加することもできます。
- **署名の前に読める。**取引はわかりやすい言葉にデコードされ、デコードできないものにはそう明示されます。
- **アルファ版です。**動作し、実際の資金も扱えますが、まだ若いソフトウェアです。少額から始めてください。[ここでいうアルファの意味](/blog/vela-is-in-alpha)。
