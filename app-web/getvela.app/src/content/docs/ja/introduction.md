# 概要

Vela は EVM ネットワーク向けの**セルフカストディのスマートウォレット**です。鍵は
あなたのものですが、書き写すシードフレーズはありません。署名は、顔や指紋で使う
パスキーで行います。

このドキュメントでは、始め方、ウォレットの作成、トークンの移動、そしてその裏側に
あるセキュリティモデルを説明します。

## 短くまとめると

- **セルフカストディ。** あなたの資金を動かせるのは、あなたしか使えない鍵だけです。
  Vela（会社）はあなたのお金を動かすことも、凍結することも、取り戻すこともできません。
- **シードフレーズなし。** 署名鍵は、端末のセキュアな領域に保管されたパスキーです。
  なくしたり、フィッシングで抜かれたりする 12 個の単語は存在しません。
- **Safe のスマートアカウント。** 各ウォレットは
  [Safe](https://github.com/safe-fndn/safe-smart-account)
  のスマートコントラクトで、ERC-4337 のアカウント抽象化で動きます。だからこそ、
  パスキーで署名でき、承認する前にすべての取引を読めます。
- **12 ネットワーク、ひとつのアドレス。** Ethereum、BNB Chain、Polygon、Arbitrum、
  Optimism、Base、Avalanche、Gnosis、Unichain、Tempo、Monad、World Chain——さらに
  自分で追加したネットワークまで、すべて同じアドレスです。
- **読める署名。** ディスクリプタがある限り、取引は人が読める意図に変換されます
  （ERC-7730）。ない場合は、できる範囲のデコードに切り替えたうえで警告します。
  読み解けない呼び出しは、隠さずに印を付けます。
- **オープンソース。** ウォレットとそのすべてのサービスは
  [GitHub で公開](https://github.com/mondaylabsltd/vela-wallet)されており、
  何をしているのか誰でも確かめられます。
- **まだアルファ版です。** Vela は動きますし、実際のお金も入っていますが、何年もの
  本番運用で鍛えられたわけではありません。少額から始めてください。
  [アルファについての記事](/blog/vela-is-in-alpha)に、その意味を書いています。

## 誰のためのものか

Vela は、シードフレーズの管理という落とし穴なしに本当のセルフカストディを望む人
——そして一度それで痛い目を見た人——のために作っています。自分のスマートフォンの
ロックを解除できるなら、Vela は使えます。
