# パスキーのしくみ

Vela のセキュリティモデルはひとつの考え方に乗っています。ウォレットを支配する鍵は
**パスキー**であり、端末が生成して OS が保管し——Vela を含めどのアプリも読めません
——顔や指紋で認証したときだけ使われる、ということです。

## パスキーとは何か

パスキーは、端末が生成する公開鍵と秘密鍵のペアです。**秘密鍵**は OS のパスキー基盤
——Apple なら iCloud キーチェーン、Android なら Google パスワードマネージャー——が
エンドツーエンド暗号化で保管するので、どのアプリも読み出せず、複製もできません。
アプリが受け取るのは鍵ではなく、認証後に*端末に署名を依頼できる*という権利だけです。

これは Apple Pay や生体ロック解除を守っているのと同じ技術です。

<Callout type="info" title="ここが要点">
アプリは——Vela も含めて——署名を要求できますが、秘密鍵を見ることは決してありません。
顔や指紋は「端末が署名すること」を認可するだけで、鍵そのものは OS の中に、
エンドツーエンド暗号化されたまま残ります。
</Callout>

## 盗み出せる秘密がない理由

フィッシングは、あなたに秘密を差し出させることで成立します。シードフレーズなら、
その秘密は偽ページに打ち込める 12 個の単語です。パスキーには、**打ち込める秘密が
そもそもありません**。詐欺サイトが「パスキーを入力してください」と言うことはできない
のです。パスキーは入力するものではなく、生体認証が門番をするハードウェア操作だから
です。

セルフカストディで資金を失う最も多い経路が、これで消えます。

## 取引に署名する感覚

1. Vela で取引を確認します。
2. 端末が Face ID / Touch ID を求めます。
3. 端末がパスキーで取引に署名します。
4. Vela が署名済みの取引をネットワークへ送ります。

スマートフォンのロック解除と同じ動作です。実際、端末がふだんから他の場面で使って
いるのと同じパスキーの仕組みだからです。

<Callout type="warning" title="端末そのものの安全は今も重要">
パスキーは遠隔からの攻撃とフィッシングに非常に強い一方、ロック解除済みの端末を手に
していて生体認証も通せる相手は防げません。端末のパスコードを必ず設定し、信頼でき
ない相手にロック解除済みのスマートフォンを渡さないでください。
</Callout>

## 残りはどこにあるのか

パスキーの**公開鍵**は小さなオンチェーンのインデックスに公開され、新しい端末でも
ウォレットを取り戻せるようにしています。それが次のページの主題です：
[復旧とサインイン](/ja/docs/recovery)。
