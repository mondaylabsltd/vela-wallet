# ウォレットを作成する

ウォレットの作成には 1〜2 分かかります。[wallet.getvela.app](https://wallet.getvela.app/) のウェブウォレット（または拡張機能、デスクトップアプリ、スマートフォンアプリ）を開き、**ウォレットを作成**を選びます。

## 手順

1. **ウォレットに名前をつけます。**名前は見分けるためのものですが、鍵と一緒に公開のレジストリに書き込まれます。公開される情報として扱い、個人的な内容は入れないでください。
2. **何が起きるかを確認します。**公開鍵とウォレット名がオンチェーンに書き込まれること、秘密鍵は端末やセキュリティキーの中に残ること、そして[利用規約](/terms)と[プライバシーポリシー](/privacy)に同意することに、チェックを入れます。
3. **最初の鍵を作ります。**方法を選びます。**この端末**（Face ID、Touch ID、指紋、Windows Hello）、**スマホまたはタブレット**（アプリが対応していれば、QR コードを読み取ってその端末で作成）、または **USB セキュリティキー**です。端末がパスキーを作成すると、そのパスキーで一度署名します。こうして、先に進む前に鍵が本当に使えることをアプリが確かめます。
4. **必要なら、鍵を追加します。**種類を問わず、合計で最大 7 本まで。そのどれか 1 本だけで署名できるようになります。唯一の鍵がどこにも同期されない場合（セキュリティキーや Windows Hello）、アプリは 2 本目を求めます。同期されない鍵が 1 本だけだと、端末をひとつなくしただけでウォレットを失うからです。
5. **作成します。**アプリは鍵の組全体からウォレットのアドレスを計算し、その組を Gnosis Chain 上の公開レジストリに登録します。記録がオンチェーンに載ると、ウォレットが開きます。

<Callout type="warning" title="鍵はいま選んでください">
アドレスは最終的に選んだ鍵の組から計算されるため、あとから鍵を追加・削除・交換することはできません。理由と選び方は[署名鍵とセキュリティキー](/ja/docs/signers)で説明しています。
</Callout>

## ウォレットの正体

ウォレットは **Safe のスマートアカウント**です。秘密鍵が 1 つだけの普通のアカウントではなく、コントラクトです。あなたの鍵がその所有者で、どれか 1 本で取引を承認できます。関わるコントラクトはすべて[アカウントコントラクト](/ja/docs/account-contract)に挙げています。

アドレスは**どのネットワークでも同じ**で、**カウンターファクチュアル**です。つまり何もデプロイされる前に計算されるので、どのネットワークでもすぐに受け取れます。コントラクトは、そのネットワークで初めて送金するときに自動でデプロイされ、その最初の取引の手数料にデプロイ費用が含まれます。ウォレットの作成自体に費用はかかりません。

## 公開される情報

<span id="what-is-public"></span>

ウォレットを作成すると、Gnosis Chain 上の公開レジストリコントラクトに永続的な記録が書き込まれます。誰でも読むことができ、編集も削除もできません。

- 各鍵の**公開鍵**（秘密鍵ではありません）と**クレデンシャル ID**
- 各鍵の**認証器の機種**（どのパスワードマネージャーやセキュリティキーで作られたか）と、本人確認が行われたか・鍵が同期されるかを示すフラグ
- **ウォレット名**と、**各鍵の名前**
- **ウォレットのアドレス**と作成日時
- **署名済みの登録データ**そのもの

この記録は Vela の公開鍵インデックスが送信し、そのガス代も払うため、インデックスは記録を最初に目にします。記録には資金を動かせるものは何も含まれていません。これがあるからこそ、どれか 1 本の鍵で新しい端末からウォレットを見つけ直せます（[復旧](/ja/docs/recovery)）。完全な一覧は[プライバシーポリシー](/privacy)に、すべての記録は[レジストリのページ](/registry)にあります。
