# Memasang Vela

Vela berjalan **di browser Anda** — tidak ada yang perlu diunduh dan tidak ada toko
aplikasi yang harus dilewati. Buka dompet web-nya dan Anda bisa membuat atau
memulihkan dompet dalam waktu kurang dari satu menit.

<a href="https://wallet.getvela.app/" target="_blank" rel="noopener" style="display:inline-block;margin:4px 0 8px;padding:11px 22px;border-radius:10px;background:#e8572a;color:#fff;font-weight:600;text-decoration:none;">Buka dompet web →</a>

Dompet yang sama, dibangun dari satu basis kode, juga berjalan di iOS dan Android.
**Aplikasi seluler asli segera hadir** — saat rilis, passkey dan dompet Anda ikut
berpindah, karena akunnya hidup di rantai, bukan di dalam aplikasi mana pun.

## Yang dibutuhkan perangkat Anda

Vela menandatangani dengan **passkey** (WebAuthn), jadi Anda perlu perangkat dan
browser yang mendukungnya — praktis apa pun dari beberapa tahun terakhir:

| Platform | Dukungan passkey | Disinkronkan oleh |
| -------- | --------------- | --------- |
| iPhone / iPad / Mac | iOS/iPadOS 16+, Safari terbaru | iCloud Keychain |
| Android | Android 9+, Chrome terkini | Google Password Manager |
| Desktop | Chrome, Edge, Safari, Firefox terkini | Penyedia passkey platform Anda |

Agar dompet ikut berpindah ke perangkat baru, biarkan sinkronisasi passkey platform
Anda tetap menyala (iCloud Keychain di Apple, Google Password Manager di
Android/Chrome). Cara kerjanya ada di
[pemulihan & masuk](/id/docs/recovery).

## Hanya ini alamat resminya

Vela bersumber terbuka, dan justru itu intinya — tetapi itu juga berarti Anda harus
yakin sedang berada di tempat yang benar. Satu-satunya alamat resmi adalah:

- **getvela.app** — situs ini
- **wallet.getvela.app** — dompetnya

Kalau ada yang mengarahkan Anda ke tempat lain untuk "memasang Vela", berhentilah dan
cocokkan dengan dua alamat ini. Kodenya terbuka di
[github.com/mondaylabsltd/vela-wallet](https://github.com/mondaylabsltd/vela-wallet).

Berikutnya: [membuat dompet Anda](/id/docs/create-wallet).
