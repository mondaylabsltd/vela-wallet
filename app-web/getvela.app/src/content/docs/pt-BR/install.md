# Instalar a Vela

A Vela roda **no seu navegador**: não há nada para baixar nem loja de apps para
atravessar. Abra a carteira web e em menos de um minuto você cria ou restaura uma
carteira.

<a href="https://wallet.getvela.app/" target="_blank" rel="noopener" style="display:inline-block;margin:4px 0 8px;padding:11px 22px;border-radius:10px;background:#e8572a;color:#fff;font-weight:600;text-decoration:none;">Abrir a carteira web →</a>

A mesma carteira, feita a partir de uma única base de código, também roda em iOS e
Android. **Os apps móveis nativos vêm em breve** — e, quando saírem, sua passkey e
sua carteira vão junto, porque a conta vive on-chain e não dentro de um app
específico.

## O que seu aparelho precisa

A Vela assina com **passkeys** (WebAuthn), então você precisa de um aparelho e um
navegador que as suportem — na prática, qualquer coisa dos últimos anos:

| Plataforma | Suporte a passkeys | Sincronizado por |
| -------- | --------------- | --------- |
| iPhone / iPad / Mac | iOS/iPadOS 16+, Safari recente | Chaveiro do iCloud |
| Android | Android 9+, Chrome atual | Gerenciador de senhas do Google |
| Desktop | Chrome, Edge, Safari, Firefox atuais | O serviço de passkeys da sua plataforma |

Para que a carteira te acompanhe em um aparelho novo, deixe a sincronização de
passkeys ligada (Chaveiro do iCloud na Apple, Gerenciador de senhas do Google no
Android/Chrome). Como isso funciona está em
[recuperação e login](/pt-BR/docs/recovery).

## As únicas URLs oficiais

A Vela é de código aberto, e esse é justamente o ponto — mas isso também significa
que você deve ter certeza de estar no lugar certo. Os únicos endereços oficiais são:

- **getvela.app** — este site
- **wallet.getvela.app** — a carteira

Se algo te mandar para outro lugar para «instalar a Vela», pare e confira com estes
dois. O código é público em
[github.com/mondaylabsltd/vela-wallet](https://github.com/mondaylabsltd/vela-wallet).

A seguir: [crie sua carteira](/pt-BR/docs/create-wallet).
