# 创建钱包

创建钱包大约需要一两分钟。打开网页钱包 [wallet.getvela.app](https://wallet.getvela.app/)——或扩展、
桌面版、手机 App——选择**创建钱包**。

## 步骤

1. **给钱包起个名字。**名字方便你辨认，它会和你的钥匙一起写进公开注册表——请把它当作公开信息，
   不要写任何隐私内容。
2. **确认会发生什么。**你需要勾选：你的公钥和钱包名称会写上链；你的私钥留在你的设备或安全密钥里；
   以及你同意[服务条款](/terms)和[隐私政策](/privacy)。
3. **创建第一把钥匙。**选择方式：**本设备**（面容 ID、触控 ID、指纹、Windows Hello）、**手机或平板**
   （扫二维码，在那台设备上创建；视 App 是否提供），或 **USB 安全密钥**。你的设备创建通行密钥后会用它签一次名，这样
   App 能在继续之前确认这把钥匙真的可用。
4. **如果需要，再加几把钥匙。**总共最多七把，种类不限。将来任意一把都能单独签名。如果你唯一的钥匙
   没有同步到任何地方——安全密钥或 Windows Hello——App 会要求你再加一把，因为只有一把未同步的钥匙，
   丢一台设备就等于丢了钱包。
5. **创建。**App 根据完整的钥匙集合算出钱包地址，并把这组钥匙发布到 Gnosis 链上的公开注册表。这条
   记录上链之后，钱包就会打开。

<Callout type="warning" title="现在就选好钥匙">
地址由你最终确定的那组钥匙算出，所以之后无法增加、删除或替换钥匙。[签名钥匙与安全密钥](/zh/docs/signers)
讲了原因，也讲了怎么选。
</Callout>

## 你的钱包是什么

你的钱包是一个 **Safe 智能账户**——一个合约，而不是只有一把私钥的普通账户。你的钥匙是它的所有者，
其中任意一把都能授权交易。涉及的每个合约都列在[账户合约](/zh/docs/account-contract)里。

地址**在每条网络上都相同**，而且是**反事实的**：在部署任何东西之前就算好了，所以你马上就能在任何
网络上收款。你第一次从某条网络发送时，合约会自行部署，部署费用包含在这第一笔交易的手续费里。
创建钱包本身不花钱。

## 哪些内容是公开的

<span id="what-is-public"></span>

创建钱包时，会往 Gnosis 链上的一个公开注册表合约写入一条永久记录，任何人可读，无法修改或删除：

- 每把钥匙的**公钥**（绝不是私钥）和**凭证 ID**；
- 每把钥匙的**认证器型号**（由哪个密码管理器或安全密钥生成），以及表示是否验证了你、钥匙是否同步的标志位；
- **钱包名称**和**每把钥匙的名称**；
- **钱包地址**及其创建时间；
- **签名后的注册数据**本身。

这条记录由 Vela 的公钥索引提交并支付 gas，所以它会最先看到记录内容。记录里没有任何能动用你资金的东西；
正是它让你的任意一把钥匙能在新设备上重新找到钱包（见[恢复](/zh/docs/recovery)）。完整清单见
[隐私政策](/privacy)，[注册表页面](/registry)可以看到所有记录。
