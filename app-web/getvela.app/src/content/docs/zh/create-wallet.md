# 创建你的钱包

创建一个钱包大约需要一分钟，加上一次生物识别确认。打开网页钱包
[wallet.getvela.app](https://wallet.getvela.app/)，选择**创建钱包**。

## 步骤

1. **给钱包起个名字。** 起个名字，方便你之后认出这个账户，也方便在另一台设备上
   登录时辨认。它和你的公钥存在一起，所以请当成公开信息——别把任何私密内容写进去。
2. **确认几件基本的事。** 一份很短的清单，确认你明白 Vela 是自托管的、而且仍然是
   内测软件，里面有[隐私政策](/privacy)和[服务条款](/terms)的链接。
3. **创建你的通行密钥。** 出现提示时，用 **Face ID、Touch ID 或者指纹**验证身份。
   这会生成一把 WebAuthn（P-256）通行密钥，由你的设备保管，Vela 永远看不到。
   这里没有「抄助记词」那一步，因为根本就没有助记词。
4. **完成。** Vela 会显示你的钱包地址，你就进去了。你可以核对地址，然后登录进入
   自己的钱包。

## 你的钱包到底是什么

这一部分大多数钱包不会解释——但它决定了 Vela 是怎么运作的。

你的 Vela 钱包是一个 **Safe 智能账户**（一个智能合约），而不是一个普通的
「外部拥有账户」。你的通行密钥是这个账户的所有者；ERC-4337 那一套让你可以只靠
脸或者指纹来操作它。

<Callout type="info" title="在每条网络上都是同一个地址">
Vela 由你通行密钥的公钥推导出地址，所以它在以太坊、Base、Arbitrum、Gnosis
以及其它所有受支持的网络上完全一致。一个地址，到处都能给。
</Callout>

还有一个很有用的后果：这个地址是**反事实（counterfactual）**的。它在链上部署任何
东西之前就算得出来，所以**在钱包合约存在之前，你就可以往这个地址收款**。合约会在
你第一次在某条网络上发交易时，用它自己的余额付钱、把自己部署上去。

## 刚才你的钥匙发生了什么

- 你的设备生成了一对**通行密钥的密钥对**。
- **私钥**由你操作系统的通行密钥服务保管（iCloud 钥匙串或者 Google 密码管理器），
  端到端加密存储并在你的设备之间同步——任何应用都看不到它，Vela 也一样。
- **公钥和你起的名字**会发布到 Vela 的通行密钥索引，它同时把公钥写进 Gnosis Chain
  上一份任何人都读得到的记录，好让你的账户在新设备上还能被找回来。
  见[恢复与登录](/zh/docs/recovery)。
