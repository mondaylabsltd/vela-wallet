# 简介

Vela 是一个面向 EVM 网络的**自托管智能钱包**。钥匙在你手上，但没有助记词要抄下来——
你用通行密钥签名，靠的是你的脸或者指纹。

这份文档讲怎么上手、怎么创建钱包、怎么转移代币，以及它背后的安全模型是怎么回事。

## 一句话版本

- **自托管。** 你的资金由一把只有你能用的钥匙控制。Vela（这家公司）无法转移、
  冻结或者找回你的钱。
- **没有助记词。** 你的签名钥匙是一把存在设备安全硬件里的通行密钥。不存在
  会丢、会被钓走的十二个单词。
- **一个 Safe 智能账户。** 每个钱包都是一个 [Safe](https://github.com/safe-fndn/safe-smart-account)
  智能合约，通过 ERC-4337 账户抽象来操作——正是它让你可以用通行密钥签名，
  并且在批准之前读懂每一笔交易。
- **12 条网络，同一个地址。** 以太坊、BNB Chain、Polygon、Arbitrum、Optimism、
  Base、Avalanche、Gnosis、Unichain、Tempo、Monad 和 World Chain——再加上你
  自己添加的网络——全都是同一个地址。
- **看得懂的签名。** 只要有对应的描述符，交易就会被解码成人能读懂的意图
  （ERC-7730）；没有的话，Vela 会退回到尽力而为的解码并给出警告。解不开的调用
  会被标出来，而不是藏起来。
- **开源。** 钱包和它的全部服务都[公开在 GitHub 上](https://github.com/mondaylabsltd/vela-wallet)，
  任何人都可以核实它们到底做了什么。
- **仍是内测软件。** Vela 能用，也真的在存放真金白银，但它还没有经过多年的生产
  环境打磨。先从小额开始。[内测说明](/blog/vela-is-in-alpha)讲清楚了这意味着什么。

## 它为谁而做

Vela 是为那些想要真正自托管、又不想被助记词管理坑到的人做的——也为那些已经被
坑过一次的人。只要你解得开自己的手机，你就用得了 Vela。
