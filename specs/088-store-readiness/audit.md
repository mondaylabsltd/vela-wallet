# Vela Wallet — store test-submission audit (Part 2)

Audited 2026-10-01, read-only, against `main` @ `67e2d193d` in `/Volumes/data/production/vela-wallet`.
Requirements this audit checks against are in `requirements.md` (same folder), with the official sources.
Live checks run today: `getvela.app/.well-known/assetlinks.json`, `getvela.app/.well-known/apple-app-site-association`,
Apple's AASA CDN copy, `getvela.app/privacy`, `getvela.app/terms`, `/support`, `/about`, `/docs`.
Binary checks: `llvm-readelf -l` on the native libraries (NDK 27.1) and on the last local debug APK
(`app/build/outputs/apk/debug/app-debug.apk`, built 2026-09-27); `codesign -d --entitlements` on the last
signed `Debug-iphoneos/VelaWallet.app`; `security cms -D` on the local provisioning profiles.

Verdicts: **BLOCKER** = the test submission fails, or testers cannot create or sign in to a wallet ·
**SHOULD-FIX** = fix in code or docs before external testing or production · **OK** ·
**OWNER-ACTION** = only the owner can do it, in Play Console, App Store Connect, the site, or a keystore.

Paths are relative to the repo root unless they are absolute. `AND/` = `app-android/vela-wallet/`,
`IOS/` = `app-ios/VelaWallet/`.

## 4. Prioritized list

**Timing:** a Play app's **first** release is reviewed, even on the internal track ("a few hours or up to seven days"). Internal testers may not have the Android build tomorrow even if it is uploaded tomorrow. iOS internal TestFlight has no review: a build is testable once it processes and export compliance is set. External TestFlight waits for Beta App Review on the first build, usually under 24 h, but Apple publishes no SLA for TestFlight.

### A. Code changes before tomorrow's test submissions

1. **Android upload signing (A4) — BLOCKER.** Add a `release` `signingConfig` that reads the keystore path and passwords from env or a gitignored `keystore.properties` (`AND/app/build.gradle.kts:58-64`), or `jarsigner` the CI AAB with the upload key. Without one of these, Play refuses the bundle.
2. **Android JNA ≥ 5.17.0 (A6) — BLOCKER.** Change `AND/gradle/libs.versions.toml:16`. x86_64 `libjnidispatch.so` is 4 KB-aligned, and JNA < 5.16 crashes on 16 KB-page devices. Rebuild and run `llvm-readelf -lW` on every 64-bit `.so` in the AAB. Fallback for today only: drop `x86_64` from `abiFilters` (`build.gradle.kts:54`) and from `rust/scripts/build-android.sh:30`.
3. **iOS entitlement check (I10).** Do one Archive → Distribute dry run. If `com.apple.security.smartcard` (`VelaWallet.entitlements:40-41`) causes a profile mismatch, remove it.
4. **Build numbers (A2/I2).** `versionCode` and `CURRENT_PROJECT_VERSION` must be above anything already uploaded. The Expo/EAS era may have used some.
5. **Fix the export-compliance comment (I7).** `Info.plist:84-90`; keep the value `false`.
